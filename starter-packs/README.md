# Starter Packs

Each starter pack is a copy-pasteable bundle for one pattern. Every pack contains:

- `contract.ts`
- `fixture.json`
- `diagram.mmd`
- `implementation-checklist.md`
- `testing-checklist.md`

## How To Use A Pack

1. Copy the contract into your shared frontend models layer.
2. Use the fixture to build the first component state or Storybook story.
3. Render the Mermaid diagram to align interaction flow with engineers and designers.
4. Follow the implementation and testing checklists before wiring live backend data.
