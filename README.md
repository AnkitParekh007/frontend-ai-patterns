# Frontend AI Patterns

Angular and TypeScript patterns for AI frontend systems: streaming UX, RAG citations, tool calling, MCP tools, approvals, state machines, and guardrails.

## Goal

This repo is a practical cookbook for AI frontend architecture. It is designed to be interview-safe public proof of how to think about AI UX in enterprise Angular applications.

## Patterns

1. Streaming message UX
2. RAG source cards
3. Tool-call timeline
4. Action approval flow
5. Agent state machine
6. Context serializer
7. MCP tool UI
8. Human-in-the-loop
9. Error recovery and retry
10. Enterprise guardrails

## What This Proves

- AI frontend architecture literacy.
- Angular and TypeScript implementation patterns.
- Ability to explain tradeoffs for enterprise copilots.
- Safety-first thinking around tool execution and user approval.
