# Angular AI Frontend Checklist

- [ ] Model explicit agent states and render them visibly.
- [ ] Stream assistant content with loading, stalled, retry, and completed states.
- [ ] Render RAG citations with title, snippet, confidence, and provenance metadata.
- [ ] Show tool calls as a timeline or event feed, not hidden console output.
- [ ] Gate high-risk actions behind an approval UI.
- [ ] Serialize route, selection, role, and visible fields through a whitelist.
- [ ] Keep model/provider credentials and policy enforcement on the backend.
- [ ] Design keyboard flows for approvals, retries, and source navigation.
- [ ] Announce streaming and status changes for screen reader users.
- [ ] Test reducer transitions and mock event fixtures before UI polish.
