# GitHub Pages Plan

## Target URL

[https://ankitparekh007.github.io/frontend-ai-patterns/](https://ankitparekh007.github.io/frontend-ai-patterns/)

## Current State

The repo is markdown-first and does not yet have a dedicated docs site build. That is intentional for now: the immediate goal is content quality and reusable examples.

## Recommended Rollout

1. Publish the `docs/` folder through GitHub Pages once navigation is finalized.
2. Add a lightweight static site layer only after the content structure stabilizes.
3. Add a link-check and markdown lint workflow before public launch.
4. Add screenshots or GIFs after at least four pattern pages have stable visuals.

## Suggested MVP Navigation

- Home: README excerpt and pattern index
- Architecture: [architecture.md](architecture.md)
- Pattern pages: `/patterns/*`
- Examples: `/examples/*`
- Recruiter quick review: [../RECRUITER_REVIEW_GUIDE.md](../RECRUITER_REVIEW_GUIDE.md)

## Launch Checklist

- remove all placeholder URLs
- verify every local markdown link
- add at least one diagram screenshot for social sharing
- enable Pages in repository settings
- announce the repo as a cookbook, not a framework
