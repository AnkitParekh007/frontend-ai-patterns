# Accessibility Checklist

- Announce streamed assistant state changes in a live region
- Keep tool, approval, and retry controls keyboard reachable
- Pair disabled or blocked states with textual explanation
- Avoid relying on typing animation or color alone
- Preserve focus order when lists grow during streaming or tool execution
- Ensure citations and expandable tool details are screen-reader friendly
- Validate reduced-motion behavior for animated or streaming surfaces
