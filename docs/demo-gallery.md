# Demo Gallery

## Why this page exists

This repo should prove behavior, not only describe it. The live docs site renders this page as an interactive mini gallery so developers can inspect high-signal trust surfaces before reading every pattern page.

## Included demos

### Streaming states demo

Shows the difference between thinking, streaming, stalled, retryable, and completed conversation states.

### Tool timeline demo

Shows how tool execution becomes visible, reviewable, and audit-friendly instead of disappearing behind a loading spinner.

### Approval gate demo

Shows how a risky action can pause for human review, display policy context, and resume with visible operator decisions.
