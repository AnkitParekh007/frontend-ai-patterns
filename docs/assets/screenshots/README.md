# Screenshot Checklist

This folder is reserved for future visual assets once the GitHub Pages docs rollout begins.

Recommended captures:

- pattern index overview
- streaming message lifecycle state
- RAG citation card cluster
- tool-call timeline with approval checkpoint
- error recovery panel
- mobile or narrow-screen layout

Recommended formats:

- `png` for static architecture and pattern screenshots
- short `gif` clips for streaming, approval, and recovery flows

Suggested dimensions:

- `1600x900` for desktop
- `390x844` for mobile
