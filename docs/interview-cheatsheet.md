# Interview Cheatsheet

- Streaming UX: How do you indicate progress, latency, and stalled responses without confusing users?
- RAG UI: How do you place citations so evidence is useful but not overwhelming?
- Tools: How do you expose intent, execution, and results for agent tools?
- Approvals: Which actions should require approval, and what metadata should be shown?
- Context: How do you serialize UI state safely for backend orchestration?
- Recovery: Which failures are retryable, and how should the UI explain recovery choices?
- Guardrails: Which policies must be visible to end users versus enforced silently?
