# Design Review Checklist

- Does the UI show when the assistant is thinking, streaming, blocked, failed, or recovering?
- Are tool and retrieval actions visible when they materially affect trust?
- Are risky actions routed through an approval state with explanation?
- Are citations inspectable without overwhelming the primary task?
- Does the UI explain policy or permission blocks clearly?
- Can a developer describe the reducer or state transitions without hand-waving?
- Are accessibility announcements defined for streamed or approval-heavy flows?
